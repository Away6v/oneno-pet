# 01 · 功能说明

> 本文描述 oneno 桌宠**当前版本已实现的功能**，只记录已落地的行为。

## 1. 项目信息

| 项     | 内容                                                                 |
| ------ | -------------------------------------------------------------------- |
| 项目   | oneno 桌宠（oneno-pet）                                              |
| 版本   | 0.1.0（唯一来源为 `src-tauri/tauri.conf.json` 的 `version`）          |
| 平台   | Windows 10 / 11 (x64)                                                |
| 定位   | 个人自用桌面宠物应用，非商用；除「检查更新」外不发起任何网络请求      |
| 人物   | 一二（one two妹）、布布（no no哥）                                   |
| 美术   | 黄小B                                                                |
| 素材来源 | 「一二布布」表情包，出处见 [`03-交互与资源规范.md`](03-交互与资源规范.md) 第 13 节 |
| 技术栈 | Tauri v2 + Vite + TypeScript（原生 DOM，无前端框架）                  |

## 2. 功能总览

| 分组       | 已实现的功能                                                                                                                 |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 桌面窗口   | 透明无边框、始终置顶、不占任务栏、可拖拽、位置记忆、大小与透明度                                                             |
| 角色       | 一二 / 布布双角色，切换即时生效并持久化                                                                                      |
| 动作播放   | 单一动作 / 随机轮播 / 顺序轮播三种模式，切换频率 1 秒 ~ 24 小时                                                              |
| 拖拽反馈   | 拖动时展示「拖拽」造型并保持，松手后回到待机造型                                                                             |
| 右键菜单   | 放射扇环菜单：中心头像，下班倒计时 / 设置 / 退出，失焦即关                                                                   |
| 气泡会话   | 独立气泡窗口贴桌宠头顶弹出、自动消失；闲置时随机碎碎念                                                                       |
| 定时提醒   | 久坐 / 喝水 / 下班三类提醒，间隔型与每日定时型，可自定义文案与关闭方式                                                       |
| 下班倒计时 | 独立面板窗口贴在人物下方、中轴与人物对齐（贴屏幕底部时翻到上方）；每秒刷新剩余时间；菜单项即开关                             |
| 素材管理   | 上传（按角色与类别）、网格浏览、批量删除、内置素材软隐藏                                                                     |
| 设置窗口   | 总览 / 宠物设置 / 素材库 / 软件 / 提醒 / 关于 六个页面，改动即时生效                                                         |
| 系统集成   | 系统托盘（显示隐藏 / 设置 / 退出）、开机自启（注册表 Run 项）、单实例（重复启动不会叠出多只桌宠，而是唤起已有那只）          |
| 数据持久化 | 配置与素材全部保存在本机 `%APPDATA%\com.oneno.pet\`                                                                          |

## 3. 桌面窗口

桌宠本体是透明窗口，运行时边长 = 宠物大小 + 12（`tauri.conf.json` 中初始配置为 160×160）。

| 行为       | 说明                                                                               |
| ---------- | ---------------------------------------------------------------------------------- |
| 透明无边框 | 无标题栏、无边框、无阴影，仅显示宠物本体                                           |
| 始终置顶   | 常驻桌面最上层                                                                     |
| 不占任务栏 | 不出现在任务栏与 Alt+Tab 中                                                        |
| 拖拽移动   | 左键按住拖动窗口；位移超过 5px 才判定为拖拽                                        |
| 单击       | 无动作绑定                                                                         |
| 位置记忆   | 松手后写入配置；重启恢复到上次位置                                                 |
| 位置校正   | 记忆坐标越界（显示器变更）时回到屏幕中央；始终收拢进显示器工作区，避免被任务栏遮挡 |
| 宠物大小   | 20 ~ 200 px 可调（设置页滑杆，步进 4）                                             |
| 透明度     | 30% ~ 100% 可调（设置页滑杆，步进 5）                                              |

## 4. 角色与素材

### 4.1 角色

- 内置 **一二**（`yier`）与 **布布**（`bubu`）两个角色。
- 在设置页切换，桌宠立即变为对应角色；重启后恢复上次选择。

### 4.2 内置素材

随程序打包，共 **108 个**（一二 67 个、布布 41 个），按角色存放在 `public/assets/<角色>/`，由 `src/core/characters.ts` 静态登记。每个文件即一个可播放造型。

> 素材出处：「一二布布」原作形象，作者 **黄小B**。主要来源为知乎专栏 [《全网最全【一二布布】动态表情包》](https://zhuanlan.zhihu.com/p/557914631)，另有[花瓣画板](https://huaban.com/boards/62437516)补充。完整说明见 [`03-交互与资源规范.md`](03-交互与资源规范.md) 第 13 节。

| 类别   | 说明                                                   |
| ------ | ------------------------------------------------------ |
| `idle` | 待机造型，由动作模式驱动展示（绝大多数素材）           |
| `drag` | 拖动桌宠时展示（每角色 1 个：`<角色>-hi.png`，透明底） |

### 4.3 自定义素材

- 在设置页「素材库」上传，可选择归属**人物**与**素材类型**（待机 / 拖拽）。
- 支持格式：`jpg / jpeg / png / webp / svg / gif`（含动图）。
- 上传的文件会拷贝到本机数据目录并登记，仅保存在本地。

### 4.4 素材删除

| 素材类型 | 删除行为                                                       |
| -------- | -------------------------------------------------------------- |
| 内置     | 软隐藏：只记入配置的隐藏列表，不删文件，执行「恢复默认」即复原 |
| 自定义   | 真正删除磁盘文件与登记记录                                     |

- 约束：每个类别（待机 / 拖拽）都至少保留一个素材，删到只剩一个时会被拒绝。
- 支持「管理」模式批量勾选删除；删除命中当前头像或单一动作选定造型时，相应配置自动回退。

## 5. 动作播放

| 模式     | 行为                                       |
| -------- | ------------------------------------------ |
| 单一动作 | 固定展示指定的一个待机造型，不计时         |
| 随机轮播 | 按固定间隔从待机池随机取一个，避免连续重复 |
| 顺序轮播 | 按固定间隔按顺序循环待机池                 |

- 默认模式为「随机轮播」，默认间隔 60 秒。
- 切换频率可调：范围 **1 秒 ~ 24 小时**，单位支持秒 / 分 / 小时（仅影响输入换算，存储恒为毫秒）。
- 单一模式下可在设置页指定具体造型；选定造型失效时自动回退到第一个可用造型。
- **拖拽造型**：开始拖动时从拖拽池随机取一个并保持整个拖拽过程，松手后回到待机；拖拽结束只由真实鼠标释放判定，不受切换间隔影响。
- **平滑切换**：双缓冲 `<img>` 交叉淡入（240ms），启动时预载当前角色全部造型，避免首次拖拽出现加载停顿。
- **省电**：窗口被隐藏或遮挡时暂停定时器，恢复时继续。
- 加载失败的素材会被临时剔除，不会卡在坏图上。

## 6. 右键菜单

右键桌宠弹出**放射扇环菜单**（480×480 透明窗口，中心即头像）。

| 部分     | 内容                                                                                             |
| -------- | ------------------------------------------------------------------------------------------------ |
| 中心     | 当前角色的圆形头像（可在设置页更换）                                                             |
| 一级项   | 下班倒计时、设置、退出（危险色），扇环围绕头像排布，逐项绽放入场；倒计时开启时该项以主强调色高亮 |
| 二级项   | 支持任意层级展开：点击带子项的父项即在更大半径展开二级扇环                                       |
| 朝向     | 默认朝左；贴近屏幕左缘时自动翻向右，避免出屏                                                     |
| 关闭     | 点击菜单外、失焦、按 Esc、点击中心头像                                                           |
| 入场动画 | 头像缩放绽放 + 扇面依次错峰浮现（`prefers-reduced-motion` 下自动降级）                           |

## 7. 气泡会话框

独立的气泡窗口（300×170 透明、点击穿透、置顶不抢焦点），用于让桌宠「说话」。

| 项         | 说明                                                                                      |
| ---------- | ----------------------------------------------------------------------------------------- |
| 定位       | 由主窗口按桌宠几何计算：贴在桌宠头顶；头顶空间不足时翻到下方                              |
| 尖角       | 尖角始终指向桌宠；气泡被屏幕边缘夹住时尖角在气泡内横移                                    |
| 内容       | 文本（支持换行）；可选图标（提醒类）                                                      |
| 自动消失   | 按文本长度估算 3 ~ 8 秒后自动收起                                                         |
| 收起时机   | 拖拽桌宠、桌宠被隐藏 / 遮挡时立即收起                                                     |
| 闲置碎碎念 | 空闲时每隔 45 ~ 90 秒随机弹出一句预设短句（7 句），不与上一句重复；拖拽中或窗口隐藏时跳过 |

- 气泡由跨窗口事件驱动，任意窗口都可以让桌宠说话（事件 `oneno-speak`）。
- 预设短句写在 `src/main.ts` 的 `CHATTER_PHRASES` 中。

## 8. 下班倒计时面板

一个**与气泡会话框互相独立**的窗口（100×50 透明、点击穿透、置顶不聚焦），用来盯住距离下班的剩余时间。

| 项       | 说明                                                                                                                       |
| -------- | -------------------------------------------------------------------------------------------------------------------------- |
| 打开     | 右键菜单点「下班倒计时」；再点一次即关闭（菜单项本身就是开关）                                                             |
| 位置     | 优先贴在人物**下方**；桌宠贴近屏幕底部时自动**翻到人物上方**（气泡始终压在其上，不会层级冲突）。横向中轴始终与人物中轴对齐 |
| 层级     | 翻到上方与气泡重叠时，**气泡在上层**（手动气泡带确认按钮，必须可点）                                                       |
| 跟随     | 拖动桌宠时面板同步跟随，松手后自动对齐                                                                                     |
| 目标时间 | **复用**「提醒 → 下班提醒」里设置的时间点（`reminders.offwork.atTime`），与该提醒是否启用无关                              |
| 刷新     | 每秒重算一次剩余时间，显示为 `HH:MM:SS`                                                                                    |
| 到点     | 卡片转为暖色强调并显示「下班啦」，**一直保持**直到手动关闭；跨过零点后自动按明天的下班时间重新计时                         |
| 显隐联动 | 桌宠被托盘隐藏 / 遮挡时，面板一并收起                                                                                      |
| 交互     | 面板全程点击穿透，不拦截任何鼠标操作，也不抢焦点                                                                           |
| 持久化   | 面板开合状态**不写入配置**，重启后默认关闭                                                                                 |

## 9. 设置窗口

单例窗口（关闭即隐藏，再次打开聚焦复用），左侧导航六个页面：

### 总览

展示当前角色头像、名称、一句话描述与标语。

### 宠物设置

| 分组 | 项                                                                                  |
| ---- | ----------------------------------------------------------------------------------- |
| 外观 | 人物切换、头像设置（从该角色素材库中点选）、宠物大小、透明度                        |
| 行为 | 动作模式（单一 / 随机 / 顺序）、指定动作（单一模式）、切换频率（数值 + 秒/分/小时） |

### 素材库

- 选择人物 → 类型筛选（全部 / 待机 / 拖拽）→ 缩略图网格。
- 「＋ 上传素材」：文件对话框选图，归入当前所选人物与类型（筛选为「全部」时默认归入待机）。
- 「管理」：进入管理模式后网格出现勾选角标，支持全选 / 删除所选批量操作。
- 内置素材带「内置」角标；所有素材均可删除（内置为软隐藏，详见 4.4）。

### 软件

- 开机自动运行开关（以 Windows 注册表真实状态为准，写入失败会回滚开关并提示）。
- 版本更新：显示当前版本、手动检查更新、一键升级（自动下载 → 验签 → 静默安装，装完由安装程序拉起新版），以及「自动检查更新」开关。
  「发现新版本」处会显示发布日期与更新说明（取自 `CHANGELOG.md`）；自动检查有两个触发点 ——
  桌宠启动约 20 秒后、以及打开设置窗口时，都只提示不自动安装，且共用 6 小时节流。

### 提醒

三类提醒各一张卡片，配置项结构一致：

| 提醒     | 触发方式                                    | 默认值        |
| -------- | ------------------------------------------- | ------------- |
| 久坐提醒 | 每隔一段时间（1 分 ~ 8 小时，单位秒/分/时） | 关闭，45 分钟 |
| 喝水提醒 | 每隔一段时间（1 分 ~ 8 小时，单位秒/分/时） | 关闭，60 分钟 |
| 下班提醒 | 每天固定时间点（HH:MM）                     | 关闭，18:00   |

每类可配置：**启用开关**、**触发间隔 / 时间点**、**关闭方式**（自动关闭＝到时收起；手动关闭＝气泡上出现确认按钮，需点击才关）、**提醒内容**（留空回退默认文案，上限 80 字）。未启用时其余配置行自动折叠。

### 关于

- 展示人物作者、程序作者、软件版本与版权说明。

所有改动即时落盘并广播给桌宠窗口，底部提供「恢复默认」（保留桌宠当前位置与开机自启设置）。

## 10. 系统托盘

| 操作             | 行为                         |
| ---------------- | ---------------------------- |
| 左键单击托盘图标 | 切换桌宠显示 / 隐藏          |
| 右键菜单         | 显示 / 隐藏桌宠、设置…、退出 |

托盘图标复用应用图标，桌宠被隐藏后仍可通过托盘操作。

## 11. 数据与配置

应用数据保存在 `%APPDATA%\com.oneno.pet\`：

```
%APPDATA%\com.oneno.pet\
├── config.json              # 应用配置
└── assets\
    ├── manifest.json        # 自定义素材登记表
    ├── yier\                # 一二的自定义素材
    └── bubu\                # 布布的自定义素材
```

`config.json` 记录的内容：

| 字段               | 含义                                                        |
| ------------------ | ----------------------------------------------------------- |
| `activeCharacter`  | 当前角色                                                    |
| `avatarIds`        | 每个角色选定的头像素材 id                                   |
| `hiddenBuiltins`   | 每个角色被隐藏的内置素材 id                                 |
| `petPosition`      | 桌宠窗口坐标（`null` 表示居中）                             |
| `petSize`          | 桌宠大小                                                    |
| `petOpacity`       | 桌宠透明度                                                  |
| `behaviorMode`     | 动作模式                                                    |
| `singleActionIds`  | 单一动作模式下每个角色选定的造型                            |
| `idleIntervalMs`   | 切换间隔（毫秒）                                            |
| `idleIntervalUnit` | 切换频率的显示单位                                          |
| `autostart`        | 开机自启（以注册表为准，此字段仅作回填镜像）                |
| `autoCheckUpdate`  | 是否静默检查更新（桌宠启动后 / 打开设置窗口时各探一次，共用 6 小时节流） |
| `reminders`        | 三类定时提醒的配置（启用 / 间隔或时间点 / 关闭方式 / 文案） |

删除该目录即可恢复到初始状态（仅保留内置素材）。
